# بروشور آنلاین بانی بن — V4

این نسخه دقیقاً برای یک صفحه‌ی بلند و اسکرولی ساخته شده و شامل **۴۰ محصول تصویری** است.

- عکس هر محصول به‌صورت بزرگ نمایش داده می‌شود.
- تصاویر از بروشورهای اصلی استخراج و گلچین شده‌اند.
- توضیحات اضافه حذف شده‌اند.
- لوگوی بانی بن با پس‌زمینه شفاف استفاده شده است.
- پروژه کاملاً Static و آماده‌ی GitHub Pages است.

## انتشار روی GitHub Pages

1. یک Repository بساز؛ پیشنهاد: `banibon-health-products`
2. محتویات این پوشه را داخل Repo آپلود کن.
3. Settings → Pages
4. Source: `Deploy from a branch`
5. Branch: `main`
6. Folder: `/ (root)`

بعد از چند دقیقه سایت روی آدرسی شبیه زیر بالا می‌آید:

`https://YOUR-USERNAME.github.io/banibon-health-products/`
